# 企画書たたきの改訂

## 決まっていること
- 聞き手：{{AUDIENCE}}／目的：{{PURPOSE}}／枚数：{{SLIDES}} 枚／発表時間：{{MINUTES}} 分
- 表紙に書くもの：{{COVER}}（「入れない」の項目は書かない。仮の社名・日付・伏せ字を作らない）

## やること
- 指示に沿って直し、指示に無いスライドはそのまま残してください。
- 1枚＝1メッセージ、bullets は 3〜5 個・40字以内。
- 数字は原案にあるものだけを使う（「原案にない数字」の指摘があれば、その数字を消すか原案の数字に戻す）。

## 出力
JSON だけを返してください。
