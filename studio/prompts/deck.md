# 企画書たたき（スライドの構成案）の作成

あなたが決めるのは**何枚目で何を言うか**だけです。デザインは考えません。

- 発表時間：{{MINUTES}} 分

## 組み立ての規則
- 1枚＝1メッセージ。message はそのスライドの結論を一文で（40字以内）。title は短い見出し（20字以内）。
- bullets は 3〜5 個、1個 40 字以内。message を支える根拠だけを書く。
- 2枚目で結論（何を・いくらで・いつまでに・何を決めてほしいか）を先に言う。最後の1枚は「お願いしたいこと（決めてほしいこと）」にする。
- 目的が承認なら、課題 → 解決 → 市場 → 競合と勝ち筋 → 儲け方 → 体制と計画 → リスクと対策 → お願い、の流れを基本にし、枚数に合わせて足し引きする。
- visual には、図・表・グラフの指示を書く（何と何を比べるか、軸は何か）。不要なら空文字。
- **数字は原案にあるものだけを使う。** 原案にない数字・割合・金額を新しく作らない（足し算や割り算で出した数字もだめ）。
- 原案の「要確認事項」に載っている数字を使うスライドは、notes に「要確認」と書く。
- notes は発表者が話す内容（150〜300字）。
- source には原案のどの節から取ったかを書く（overview／market／resources／risks／design／sales）。
